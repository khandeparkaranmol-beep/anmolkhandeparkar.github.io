How It Works

Point it at your existing codebase. Three commands from install to test results.

01
Scan
AST-scans your codebase to detect agents and frameworks — CrewAI, LangGraph, AutoGen, or raw Python.
riftcheck init
02
Generate
Scaffolds adversarial test scenarios with fault injection configs and property assertions.
scenario.yaml
03
Run
Executes each scenario N times, injecting faults between agents and checking 16 properties per run.
riftcheck run
04
Report
Pass rates with Wilson confidence intervals. Open the trace viewer to see exactly where things broke.
--view
Why Multi-Run by Default
LLM-powered agents are non-deterministic. A single pass/fail tells you nothing. Riftcheck runs every scenario 5 times by default and reports statistics with confidence intervals — so you know whether 4/5 passing is signal or noise.
Why Engine-Level Fault Injection
Faults happen between message send and receive — they modify what the agent sees, not the agent itself. This means you test real agent code under adversarial conditions without modifying a single line of your implementation.

What It Checks

16 stateless property checkers across four categories. Each receives a complete trace and returns pass/fail with evidence.

🔒
Information Flow
Detects private data leaking between agents who shouldn't share it. Budget numbers, credentials, internal state.
🔄
Coordination
Catches deadlocks, infinite loops, and agents waiting on each other forever. The politeness loop problem.
🧠
Reasoning
Verifies agents maintain consistent logic, don't contradict themselves, and follow their assigned roles.
✅
Completion
Ensures tasks aren't marked done prematurely, outputs meet quality bars, and conversations converge.

Trace Viewer

A single HTML file. No server, no account, no signup. Three views to understand exactly what happened.

Spotlight
Cinematic Replay
Step through the conversation turn by turn. See agent messages, fault injections, and property check results as they happen.
Constellation
Agent Network
Visualize who talks to whom. Edge weights show message volume. Spot communication bottlenecks and isolated agents.
Timeline
Swimlane Diagram
All agents on parallel lanes with messages as arrows. See deadlocks, timing issues, and coordination patterns at a glance.

Why This Exists

Without Riftcheck
✗ Agents tested in isolation — pass individually, fail together
✗ Bugs found in production when agents interact unexpectedly
✗ Manual trace review — eyeballing logs for dozens of scenarios
✗ Single pass/fail with no statistical confidence
✗ No systematic way to inject faults or test edge cases
With Riftcheck
✓ Agents tested in conversation — the way they actually run
✓ 16 automated property checks catch issues before deploy
✓ Visual trace viewer with three purpose-built views
✓ Multi-run stats with Wilson confidence intervals
✓ 5 fault injection types simulate real-world failures
